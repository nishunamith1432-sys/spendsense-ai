# SpendSense AI

A browser-based personal money management prototype built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — layout, colors, responsive design, and visual styles
- `script.js` — transaction handling, budget calculations, savings planner, purchase simulator, and rule-based assistant

## Run locally
1. Keep all three files in the same folder.
2. Open `index.html` in a modern browser.
3. No build command or package installation is required.

## Deploy to Netlify
For this static HTML site, publish the folder containing `index.html`. No build command is required.

## Important notes
- This is a prototype, not financial advice.
- The assistant uses predefined JavaScript rules and is not connected to a live AI model or bank.
- Data is stored in the current browser's local storage.
- Do not enter real sensitive financial or banking information.
